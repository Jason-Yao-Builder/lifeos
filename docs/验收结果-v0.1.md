## 已知边界

🔴 默认 AI 是可解释的 deterministic adapter，不代表真实模型质量。

🔴 进程在 AI run 执行中被强制终止时尚无 lease 回收；正常失败可重试，后续真实 provider 接入前应补超时租约。

🔴 `apps/api/data/lifeos.db` 是早期持久化 smoke test 留下的忽略文件；当前默认数据库已统一为 `workspace/data/lifeos.db`，本轮遵守不擅自删除本地文件的约束而保留。
