## 额外边界核验

🟢 甘特候选查询会扩展前后各一日，再按工作区 IANA 时区做真实时间重叠；上海与洛杉矶 UTC 跨日均有测试。

🟢 日历与甘特保留桌面 HTML5 拖拽，同时支持 touch/pen Pointer Events、方向键微调、边缘自动滚动，并复用相同的乐观更新和失败回滚。

🟢 任务列表以三层树形展示并支持末尾落点；子任务详情可双向跳转父任务。甘特图同步支持层级缩进/折叠，绘图区不显示纵向列线，条体不再显示文字。

🟢 任务页默认只展示活跃任务与今日完成事实，并按已逾期、今日截止、未来截止、无截止安排、今日已完成分区。可分别按目标时间或实际完成时间查看今天、未来和过去；任务首次完成时在同一事务中移到有效队列末尾，刷新后顺序保持。

🟢 甘特纵向行序只由 rank、创建时间和 ID 决定；调整任务起止日期后，乐观更新、服务端重载和页面刷新均不改变其他任务行。月模式按自然月分段展示，导航按整月移动。

🟢 甘特平移及起止端拖动共用同一候选范围；拖动中显示浅色虚线预览与预计日期，松手才提交，取消、无效落点及阻塞状态不留预览。

🔴 v0.2 仍是单进程、单用户、本地 SQLite；真实模型、日内时间块、外部日历同步和多用户协作按规划留到后续版本。
